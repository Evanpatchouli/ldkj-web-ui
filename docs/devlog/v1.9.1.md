# v1.9.1

- 发布日期: 2026-08-18
- 版本: `1.9.1`

## 新增

- Button 新增原生 `loading`、`loadingText` 和 `loadingIcon` API，自动处理禁用、`aria-busy` 和重复点击保护。
- 新增 `button`、`ghost-button`、`select`、`theme` 和 `icon` 组件级导入入口。

## 优化

- 库构建改为多入口输出，并同步发布包 `exports`，支持组件级 tree-shaking。
- 图标加载器保持异步拆分，未使用图标的 Button 消费者不再携带图标模块。

## 修复

- 修复 GhostButtonGroup 使用 hover trigger 时，鼠标跨越菜单间距后无法点击选项的问题。

## 文档

- 补充 Button loading Demo、GhostButtonGroup hover 行为说明、按需导入与 tree-shaking 文档。
- 增加组件级导出、loading 状态和 hover 菜单的自动化验收说明。

## 验证

- `pnpm -s tsc --noEmit --ignoreDeprecations 5.0` 通过。
- `pnpm -s build` 通过。
- `pnpm -s build:docs` 通过。
- `pnpm -s assert:ghost-button-group`、`pnpm -s assert:button-loading`、`pnpm -s assert:package-exports` 通过。
