# v1.10.0

- 发布日期: 2026-10-20
- 版本: `1.10.0`

## 新增

- 新增 `DateTimePicker` 日期时间选择器，支持单选日期、精确到秒的循环时间滚轮、“今天零点”与“此刻”快捷操作。
- 支持草稿确认与取消、清除、禁用、键盘操作和关闭后的焦点恢复，并接入组件库根入口及 `Form.Item`。

## 优化

- 日期时间选择器适配本库主题与 `sx` 样式入口，支持深色主题和窄屏布局。
- 更新 Browserslist 浏览器兼容数据，消除数据过期警告。

## 修复

- 为 `@orama/searchbox@1.0.0-beta.13` 添加持久化依赖补丁，移除发布文件中无效的 source map 引用，消除文档开发服务的缺失文件警告。

## 文档

- 补充 `DateTimePicker` 文档、基础用法、编辑与禁用状态、表单排期示例，以及行为规则、可访问性和性能说明。
- 新增日期时间选择器的 Playwright 自动化断言，覆盖日期与时间选择、滚轮居中、减少动态效果、确认取消、清除、禁用、表单和窄屏布局。

## 验证

- `pnpm -s tsc --noEmit --ignoreDeprecations 5.0` 通过。
- `pnpm -s build`、`pnpm -s build:docs` 通过。
- `pnpm -s assert:date-time-picker`、`pnpm -s assert:docs-search`、`pnpm -s assert:package-exports` 通过。
