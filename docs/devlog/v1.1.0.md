# v1.1.0

- 发布日期: 2026-06-13
- 版本: `1.1.0`

## 新增

- 新增 `Header` 布局组件，提供 5 种使用模式：
  - **基础模式**：顶部导航栏，支持标题、Logo 与操作区插槽
  - **吸顶模式**：`sticky` 属性启用，滚动时自动吸附顶部
  - **响应式模式**：`responsive` 属性启用，自动适配移动端/桌面端布局
  - **插槽模式**：通过 `left`, `center`, `right` 插槽自定义内容分布
  - **复合模式**：组合吸顶与响应式，支持复杂业务导航场景

## 文档

- 新增 `Header` 组件文档页，含 5 组可交互演示示例
- 在布局导航侧边栏中注册 Header 文档入口
- 在组件注册表及库入口中导出 Header
