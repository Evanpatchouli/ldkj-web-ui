# v0.18.0

- 发布日期: 2026-06-08
- 版本: `0.18.0`

## 新增

- `Notification` 升级为独立通知卡片能力，新增 `NotificationProvider`、`useNotification` 与静态 `notification` facade。
- 支持标题、描述、自定义正文、操作区、通知类型、图标、位置、偏移、关闭回调和队列上限。
- 静态 `notification` 新增 `dismiss`、`clear`、`config` 与 `resetConfig`，支持全局默认展示策略。

## 优化

- 通知卡片补齐进入、离开动画与独立样式文件，按通知状态配置图标、颜色、`role` 和 `aria-live`。
- 同一 `placement + offset` 下超过队列上限时自动淘汰最早通知，避免同一区域持续堆叠。
