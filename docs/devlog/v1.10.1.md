# v1.10.1

- 发布日期: 2026-10-22
- 版本: `1.10.1`

## 优化

- `MobileStepper` 步骤头增加约 `300ms` 的高亮滑动吸附、标题宽度和文字过渡，连续切换会从当前位置接续，并支持系统“减少动态效果”设置。
- `MobileSelect`、`MobileCascader` 的弹层统一复用底部 `Drawer`，共享滑出与收回动画、滚动锁和关闭生命周期，保留移动端取消/确认栏及高度限制。

## 修复

- 修复 `Drawer` 四个方向位移动画失效、首次打开直接出现的问题；关闭时面板沿原方向收回并保持不透明，仅遮罩淡入淡出。
- 修复抽屉快速反向开关时的动画接续，以及保留内容时隐藏遮罩仍阻挡页面操作的问题。
- 修复移动端选择器触发按钮的图标垂直对齐与长文本溢出，确保自定义高度和清除选择后布局一致。
- 修复 `MobileStepper` 激活项与数字项高度不一致、数字未居中的问题，统一各尺寸的步骤头高度并保持非激活项为正圆。
- 统一浅色与深色主题的颜色变量引用，并修正次要按钮文字颜色。

## 文档

- 更新 `Drawer`、`MobileSelect`、`MobileCascader`、`MobileStepper` 的动画、状态规则、滚动策略和可访问性说明。
- 新增抽屉与移动端组件的 Playwright 回归断言，覆盖位移动画、快速切换、取消确认、触发器对齐、受限高度滚动和减少动态效果。
