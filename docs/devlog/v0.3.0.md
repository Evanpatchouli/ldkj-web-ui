# v0.3.0

- 发布日期: 2026-04-23
- 版本: `0.3.0`

## 新增

- 新增 `Chip` 的 `rounded` 属性，支持预设值与自由值
- 新增 `Button` 的 `rounded` 属性，支持预设值与自由值
- 新增 `Divider` 组件，支持水平/垂直模式、变体、对齐与线型配置
- 新增 `Flex` 组件，支持 `direction`、`justify`、`items`、`flex`、`wrap`、`gap`、`width`、`height`
- 新增 `Grid` 组件，支持 `container`、`size`、`offset`、`columns`、`spacing`、`rowSpacing`、`columnSpacing`、`wrap`、`direction`
- 文档示例统一接入 `CodeView` 卡片，支持显示/隐藏代码与复制代码
- 新增开发日志模块及版本日志索引页

## 优化

- 文档侧边栏补充 `Divider`、`Flex`、`Grid` 入口
- 补齐 `Flex`、`Grid` 组件文档与示例
- 补齐历史版本日志（`v0.1.0` ~ `v0.2.2`）
- 导航与侧边栏文案统一中文化

## 备注

- 后续每次发版请新增一个独立文件，例如 `v0.3.1.md`
