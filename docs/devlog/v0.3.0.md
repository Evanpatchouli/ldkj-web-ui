# v0.3.0

- 发布日期: 2026-04-24
- 版本: `0.3.0`

## 新增

- 新增 `Chip` 的 `rounded` 属性，支持预设值与自由值
- 新增 `Button` 的 `rounded` 属性，支持预设值与自由值
- 新增 `Divider` 组件，支持水平/垂直模式、变体、对齐与线型配置
- 新增 `Flex` 组件，支持 `direction`、`justify`、`items`、`flex`、`wrap`、`gap`、`width`、`height`
- 新增 `Grid` 组件，支持 `container`、`size`、`offset`、`columns`、`spacing`、`rowSpacing`、`columnSpacing`、`wrap`、`direction`
- 新增 `SafeArea` 组件，支持 `position`、`horizontal`、`component`，并提供 `SafeAreaTop` / `SafeAreaBottom` 快捷封装
- 文档示例统一接入 `CodeView` 卡片，支持显示/隐藏代码与复制代码
- 新增开发日志模块及版本日志索引页

## 优化

- 文档侧边栏补充 `Divider`、`Flex`、`Grid`、`SafeArea` 入口
- 补齐 `Flex`、`Grid`、`SafeArea` 组件文档
- 扩展 `Grid` 文档示例，新增 `columns`、`direction + wrap`、`nested`、`dashboard`、`form/detail` 场景
- `Grid.wrap` 增强为支持 `boolean`（`true -> wrap`，`false -> nowrap`）
- 补齐历史版本日志（`v0.1.0` ~ `v0.2.2`）
- 导航与侧边栏文案统一中文化

## 修复

- `QRCodeSizable` 与 `QRCodeCanvas` 行为对齐，新增 `fullWidth` 参数
- 二维码宽度计算优先级调整为：`fullWidth` 优先，其次沿用原有 `width -> size` 逻辑
