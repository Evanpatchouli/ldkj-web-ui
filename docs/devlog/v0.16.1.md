# v0.16.1

- 发布日期: 2026-06-02
- 版本: `0.16.1`

## 新增

- `Form` 新增 `useForm` hook，提供表单状态管理与校验能力，配套 `FormUseFormDemo`、`FormValidationDemo`、`FormWatchDemo` 使用示例。
- `Slider` 新增 `variant` 属性，支持 `solid`（纯色，默认）与 `gradient`（渐变）两种变体。

## 优化

- `Slider` 变体 `solid` 默认色改为 `blue-600`，与 `Button primary` 对齐。
- `Slider` 轨道默认粗细从 `0.58rem` 调细至 `0.4rem`。
- `Slider` 将硬编码阴影值抽为 CSS 变量，跟随 `variant` 联动。
- `InputNumber` 文档补充 `useInputNumberState` 使用示例与数字约束说明（min、max、step 传参方式及失焦归一化行为）。
- `Uploader` 小幅调整。

## 修复

- 修复 `Slider` thumb 渐变背景因 `bg-*` 编译为 `background-color` 而透明的问题。
