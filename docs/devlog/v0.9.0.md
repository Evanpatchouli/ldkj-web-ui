# v0.9.0

- 发布日期: 2026-05-07
- 版本: `0.9.0`

## 新增

- 新增 `Menu` 导航组件，支持 `items` 配置与 `Menu.Item`、`Menu.Sub`、`Menu.Group` 组合式写法。
- `Menu` 支持受控/非受控的 `selectedKeys`、`openKeys`，并提供 `menuRef` 命令式控制。
- `Menu` 支持 `multiple` 多选、`accordion` 同层手风琴展开、`indent` 层级缩进、`itemGap` 菜单项间距、`itemColors` 状态色与 `sx`。
- 新增 `useMenuRef` hook，用于创建 `Menu` 的命令式控制引用。

## 优化

- `Menu` 内部重置列表样式与列表项边距，避免 VitePress 或业务全局排版样式干扰菜单显示。
- `Menu.Sub` 头部与内部列表之间统一使用 `itemGap`，保持子菜单展开后的视觉节奏一致。
- 移除 `Menu` 中 `--menu-item-selected-hover-bg` 与 `itemSelectedHoverBackground`，选中项 hover 背景沿用 `itemSelectedBackground`。

## 修复

- 修复 `Menu` 在文档排版环境下菜单项前出现列表黑点的问题。

## 文档

- 新增 `docs/components/navigation/menu.md` 文档页。
- 新增 `MenuBasicDemo`、`MenuItemsDemo`、`MenuControlledDemo`、`MenuSxDemo`。
- 补充 `MenuMultipleDemo`、`MenuAccordionDemo`、`MenuIndentDemo`、`MenuItemGapDemo` 独立示例。
- 组件侧边栏“导航”分组新增 `Menu` 入口。
