# v0.6.0

- 发布日期: 2026-04-28
- 版本: `0.6.0`

## 新增

- 新增 `Icon` 组件，基于 `@material-symbols/svg-400` 提供按名称与变体的动态加载能力。
- 新增 `Toast` 体系：`ToastProvider`、`useToast` 与静态 `toast` facade。
- 新增 `Icon` 运行时注册能力：`registerIconLoaders`、`setIconLoaders`、`resetIconLoaders`、`getRegisteredIconNames`。
- 新增 `Box` 长按能力：`onLongPress`、`longPressDelay`。

## 优化

- Toast 动画风格对齐轻量入场/离场反馈，支持 `placement`、`duration`、`queueLimit`、`reverse`。
- 静态 `toast` 提供 `config/resetConfig`，可统一默认位置、时长与 `closable`。
- Toast 支持消息级 `closable`、`icon`、`iconColor` 配置。
- `Icon` 支持 `svg` 与 `src` 自定义图标来源。
- `Icon` 属性 `fill` 重命名为 `useColorAsFill`（语义更准确）。

## 修复

- Toast 补齐 A11y：按消息类型自动设置 `role` 与 `aria-live`，并提供可键盘访问的关闭按钮。

## 文档

- 新增 `Icon` 文档页与示例。
- 新增 `Toast` 文档页与示例。
- 新增 `Box` 的 `onLongPress` 示例。
- `Icon` 文档补充 `variant`、`size`、`color`、`title` 与 Registry API 专项 Demo。
- `Toast` 文档拆分 `useToast` / 静态 `toast` 专项 Demo，并补充多层 `ToastProvider` 与混用注意事项。
- 更新侧边栏组件目录与主题 Demo 注册。
