# v1.0.0

- 发布日期: 2026-06-09
- 版本: `1.0.0`
## 新增

- 新增 `ThemeProvider`、`useTheme`、`themeToCssVars` 与 `--ldkj-*` 主题 token，支持局部主题、根节点主题和明暗模式。

## 优化

- 将 Button、表单、浮层、通知、移动端面板、Badge、Chip、Card、Progress、Spin、Loading 等组件的默认视觉接入主题变量。

## 修复

- 调整文档站样式导入顺序，确保 `reset.css` 在 `style.css` 前加载，避免 Tailwind base 覆盖组件主题工具类。

## 文档

- 新增主题定制文档与 `ThemeBasicDemo`，补充品牌色覆盖、明暗模式、局部主题、Portal 继承和优先级说明。

## 验证

- `npx tsc --noEmit --ignoreDeprecations 5.0` 通过。
- `pnpm build:docs` 通过。
- `pnpm -s build` 通过。
- 本地主题文档页浏览器复核通过：Demo 已注册、品牌主题色生效、深色模式下组件 surface/token 可切换。
