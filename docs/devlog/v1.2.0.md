# v1.2.0

- 发布日期: 2026-06-13
- 版本: `1.2.0`

## 新增

- 新增 `Navigator` 导航组件，基于 `@radix-ui/react-navigation-menu` 实现，提供 5 种使用模式：
  - **基础模式**：水平导航栏，支持菜单项与子菜单展开
  - **复合模式**：嵌套多级菜单，支持分组与图标
  - **受控模式**：通过 `value` / `onValueChange` 外部控制菜单展开状态
  - **Header 集成模式**：与 `Header` 组件配合，实现站点级导航栏
  - **大型导航（MegaMenu）**：支持多列网格布局的下拉面板，适用于分类密集场景

## 工程

- 新增 `@radix-ui/react-navigation-menu` 依赖
- 新增 `pnpm-workspace.yaml`，配置 esbuild 构建许可

## 文档

- 新增 `Navigator` 组件文档页，含 5 组可交互演示示例
- 在导航侧边栏中注册 Navigator 文档入口
- 在组件注册表及库入口中导出 Navigator
