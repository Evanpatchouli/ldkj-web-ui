# v0.17.0

- 发布日期: 2026-06-05
- 版本: `0.17.0`

## 新增

- `Select` 从 Radix Root 别名升级为包装组件，新增 `lockScroll` 属性控制弹层打开时页面能否滚动，默认允许页面继续滚动。
- 新增公开类型 `SelectProps`，暴露 `lockScroll`、`open`、`defaultOpen`、`onOpenChange`、`dir` 等 Radix Root 属性。

## 文档

- 重构 `Select` 文档结构，按常见场景组织（受控选择、分组与分隔线、禁用与样式、页面滚动策略），示例改用业务语义文案。
- 新增「行为规则 / 优先级」章节，明确组件受控规则、样式合并优先级与 `SelectItems` 定位。
- 新增 `SelectScrollBehaviorDemo` 演示组件，覆盖 `lockScroll` 的启用与禁用效果。

## 验证

- `pnpm -s tsc --noEmit --ignoreDeprecations 5.0` 通过。
- `pnpm build:docs` 通过。
