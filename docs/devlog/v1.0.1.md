# v1.0.1

- 发布日期: 2026-06-12
- 版本: `1.0.1`

## 修复

- 修复 `Cascader` 异步加载选项时只传递当前选项而非完整路径，导致 `loadData` 回调缺少父级数据上下文。
- 修复 `Cascader` 清除按钮从触发器外部的绝对定位改为内部 Flex 布局项，消除 `pr-16` 硬编码间距。
- 修复 `Cascader` 弹出面板宽度从固定 `min-w-[320px]` 改为 `w-max` 自适应，适应窄内容场景。
- 修复 `Cascader` 选项 active 路径匹配逻辑，防止因祖先路径前缀匹配导致的误高亮。
- 补全 `Cascader` `handleSelect` 中 `useCallback` 缺失的 `fieldNames` 依赖项。

## 验证

- `npx tsc --noEmit --ignoreDeprecations 5.0` 通过。
- `pnpm build:docs` 通过。
