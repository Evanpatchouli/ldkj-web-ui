# v0.10.0

- 发布日期: 2026-05-07
- 版本: `0.10.0`

## 新增

- 新增 `Tabs` 导航组件，基于 Radix Tabs 并对齐本库 `sx`、`className/class` 与配置式 `items` API。
- `Tabs` 支持组合式 `TabsList`、`TabsTrigger`、`TabsContent`，也支持 `items` 快捷配置。

## 优化

- `TabsContent` 新增 `borderless`，用于关闭默认内容面板边框和内边距。
- `Tabs` 默认样式替换 shadcn token 类，统一为本库 slate/blue 风格。

## 修复

- 本周期无单独修复项。

## 文档

- 新增 `docs/components/navigation/tabs.md` 文档页。
- 新增 Basic、Items、SX Styling 示例。
- 补充 Borderless 独立示例。
- 补充 Custom Content 示例，展示不使用库内 `TabsContent` 的受控渲染方式。
- 组件侧边栏“导航”分组新增 `Tabs` 入口。
