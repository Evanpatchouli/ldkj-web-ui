# v1.4.0

- 发布日期: 2026-06-16
- 版本: `1.4.0`

## 新增

- 新增 `Stepper` 桌面端步进器组件，支持 vertical / compound / status / controlled 四种形态。
- 新增 `MobileStepper` 移动端步进器组件，支持胶囊标题、圆点/进度/文本指示器、滑动切换与底部操作区。
- 抽离 `shared/stepper.tsx` 通用步进器逻辑（状态管理、子项收集、索引钳制、激活判定），供两组件共享。

## 修复

- 修复 `Navigator` 导航链接文本样式优先级问题，确保自定义样式不被默认样式覆盖。

## 工程

- 升级 GitHub Actions 至 checkout/setup-node v6、upload-artifact v6、download-artifact v7。
- pnpm 版本从 9 升至 10，补充 pnpm-workspace.yaml 显式 packages 声明。

## 文档

- 为 `Stepper` 与 `MobileStepper` 编写 VitePress 文档页与 9 个交互式 Demo。
- 更新侧边栏导航项，注册 Demo 主题组件。

## 验证

- `npx tsc --noEmit --ignoreDeprecations 5.0` 通过。
- `pnpm build:docs` 通过。
