# v1.6.0

- 发布日期: 2026-06-17
- 版本: `1.6.0`

## 新增

- 新增 `RootPage` 移动端根页面容器，支持标题栏、下拉刷新、底部版权、安全区适配。
- 新增 `SubPage` 移动端子页面容器，支持返回导航与 `$parent` / `$prev` 路由目标。
- 新增 `TabRootPage` 移动端标签页根容器，支持底部 Tab 切换与路由联动。

## 优化

- `Switch` thumb 位移改用 CSS 自定义属性 `--ldkj-switch-thumb-translate` 控制，状态样式逻辑移至 `style.css` 的 `@layer components`，减少 Tailwind 变体类依赖。

## 文档

- 为 `RootPage` / `SubPage` / `TabRootPage` 编写 4 个 VitePress 交互演示示例。
- 新增 `mobile-page.md` 文档页面，注册至移动端组件侧边栏。

## 验证

- `npx tsc --noEmit --ignoreDeprecations 5.0` 通过。
- `pnpm build:docs` 通过。
