# v0.15.0

- 发布日期: 2026-05-17
- 版本: `0.15.0`

## 新增

- 新增 `Badge` 组件，支持数字/文本角标、红点模式、零值展示、`max+` 计数上限及 `neutral/primary/success/warning/danger` 语义色与 `light` 轻量风格。
- 新增 `Typography` 排版组件，支持 `h1/h2/h3/body/caption` 变体、`component` 语义标签切换及 `sx` 样式扩展。
- 新增 `Empty` 空状态组件，支持默认描述、自定义图形和操作内容，继承 `Box` 能力。
- 新增 `Image` 图片组件，支持加载占位、失败回退、重试、`aspectRatio`/`fit`/`position` 裁剪、OSS 参数拼接、picture 响应式资源、格式协商与图片预览弹层（缩放、拖拽、键盘关闭、焦点恢复）。
- 新增 `List` 列表组件，重置 `ul` 默认样式，支持原生属性透传、`bordered` 模式与 `sx` 样式入口。
- 新增多个表单组件初版草稿：`AutoComplete`、`Cascader`、`FormV2`、`InputNumber`、`InputOPT`、`Rate`、`Required`、`SliderV2`、`Uploader`。
- 新增多个交互组件初版草稿：`Alert`、`Drawer`、`Loading`、`Notification`、`Progress`、`Spin`。
- 新增 `AGENTS.md` 项目协作规范，明确组件文档与 Demo 编写规范。
