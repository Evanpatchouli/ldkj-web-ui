# v1.5.0

- 发布日期: 2026-06-16
- 版本: `1.5.0`

## 新增

- 新增 `Timeline` 时间线组件，支持 pending 加载态、left/right/alternate 位置模式、自定义节点内容。
- 为 Timeline 编写 5 个 VitePress 文档演示示例（基础用法、自定义内容、加载中、位置切换、SX 属性）。

## 优化

- `reset.css` 去掉 `@tailwind base` 依赖，改为独立手写的 CSS normalize，降低对 Tailwind CDN/构建的耦合。
- Button base 类补充 `box-border`、`appearance-none`、`cursor-pointer` 等原生重置属性，确保在新 normalize 下表现一致。
- ghost / link / text variant 显式增加 `bg-transparent`，避免浏览器默认背景干扰。

## 修复

- 修正 Timeline dot 在不同内容状态（纯圆点 vs 带 icon/loading）下的垂直偏移，拆分两套偏移量精调对齐。
- 修复 `DividerVerticalDemo` 中多余的 `variant="middle"` 属性。
- 修复 `README.dist.md` 的 UTF-8 BOM 问题。

## 文档

- 更新三份 README 中 `reset.css` 职责说明，明确其与 `style.css` 的引入顺序和用途区分。

## 验证

- `npx tsc --noEmit --ignoreDeprecations 5.0` 通过。
- `pnpm build:docs` 通过。
